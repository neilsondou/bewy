# Test Samples Project

A sample project containing code in various programming languages,
used for testing the **Bewy IDE** file icon and editor features.

## Languages Included

| Language    | File            | Description              |
|-------------|-----------------|--------------------------|
| C           | `src/main.c`    | Structs, binary search   |
| C++         | `src/shapes.cpp`| Templates, polymorphism  |
| Dart        | `src/app.dart`  | Flutter counter app      |
| Python      | `src/indexer.py` | File indexer w/ hashing |
| Java        | `src/TaskScheduler.java` | Priority queue  |
| JavaScript  | `src/server.js` | Express API server       |
| TypeScript  | `src/tasks.ts`  | Task manager w/ generics |
| Go          | `src/nearest.go`| K-nearest neighbors      |
| Rust        | `src/matrix.rs` | Matrix operations        |
| Ruby        | `src/pipeline.rb`| Pipeline pattern        |
| Swift       | `src/cache.swift`| LRU cache               |
| Kotlin      | `src/users.kt`  | Coroutines, Flow         |
| PHP         | `src/query.php` | SQL query builder        |
| Lua         | `src/scheduler.lua` | Coroutine scheduler  |
| R           | `src/analysis.r`| Statistical analysis     |
